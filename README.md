### 1. Table & Text effects
|  effect  |  Input  |  Output  |
|  ---  |   ---  |  ---  |
|  **Bold**  |  \*\*Text**  |  **Text**  |
|  *Italic*  |  \*Text*  |  *Text*  |
|  ***Bold and Italic***  |  \*\*\*Text***  |  ***Text***  |
|  ~~strikethrough~~  |  \~~Text~~  |  ~~Text~~  |
|  `inline code`  |  \`Text` ( Use Backtick )  |  `Text`  |
